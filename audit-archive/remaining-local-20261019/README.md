# 剩余本地工作副本的补充归档

此目录保存首轮发布后仍在本地的独有工作源码与审计文本，便于删除剩余项目副本后按原字节恢复。它不替代 v1.0.0 的完整模型、图片与媒体 Release，也没有重新上传大载荷或改变冻结标签。

`source-and-evidence-index.json` 逐项给出清理前路径、SHA256、分类与恢复位置。`unique-sources-and-evidence.tar.gz` 保存未被先前 Git/Release 按相同SHA覆盖的源码/文本/必要参考图，并去重相同内容；路径别名通过索引指向同一归档成员。可用标准tar在新目录展开，再按索引查找原路径。所有成员为普通文件，保留可编辑文本原字节。

历史QA/清理脚本含当时的本机路径与状态检查，作为可审阅源码归档；实际重建入口仍使用仓库主说明中的便携工具。旧日志与旧清单标注当时状态，最新发布/验收/清理状态以主仓库当前记录为准。

第三方node_modules和Python字节码是可重建缓存，不保留项目副本。测试过程中生成的诊断截图/视频抽帧也不作为唯一输入保留：原SHA、实际审查报告和两张覆盖22张Blender诊断帧的接触表已归档，源模型、影片和重建脚本可从现有Release/Git恢复。原始桌面392文件、另一课程103份独立素材和所有共享安装/技能/模型不在此次清理范围。

各内容保留原有来源与许可；不将GPL视觉、MIT helper、Breeze研究/非商业输出或字体软件混授为一个总许可。完整边界见仓库LICENSES.md。
