# v1.0.0 本地生成副本清理记录

公开发布、全部10附件真实匿名下载、3829文件SHA核对及实际浏览/声画播放/前端与Blender重建验收完成后，已按用户授权清理本任务的大型生成输出和验证副本。

- 原工作区35个明确生成目录/别名已移除。
- 实际下载包、展开的大型文件、恢复影片和前端/Blender重建副本已移除。保留主Git检出的194个冻结源码文件；删除前后逐项SHA相同，之后才更新到含验收记录及验证器修正的main。
- 两批先原子隔离，分别独立复核范围、所有条目指纹与活跃句柄，再只删除精确的两个隔离子目录。删除使用不跟随符号链接目标的目录操作。
- 桌面原项目392文件与另一项目103份独立输入在删除后再次核SHA通过；共用运行时、技能与Blender程序保留。未清理其他项目或未分类文件。
- 轻量源码、哈希清单、验收报告/截图和22张实际重建诊断图继续保留；完整模型、全部图册和影片素材仍由同一公开Release提供。

按逻辑文件大小共移除约 **15.622 GB**；同一文件系统可用空间在两次采样间净增加约 **12.422 GB**。前者包括重复/写时复制数据，后者可能受同时运行的其他任务影响，不能把逻辑大小当作精确的独立物理回收量。

冻结Release仍为 commit `82c2a2a255b66556cead58ec3444f81f1757ae68`，清单SHA256仍为 `b5122c9f67b948f15e3f476e1bcd01f447593c46a6dff80292bd61994f314877`。本记录没有改变发布附件或标签。
